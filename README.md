# 설비보전기사 3과제 용접 연습기

- `index.html` — 필릿 용접 연습기
- `leak.html` — 보수 용접·누수 연습기 (Ø12 구멍 메우기, 40A 파이프 일주 필릿, 물 붓기 누수 시험, 도면 ①–⑧)

## 필릿 용접 연습기

설비보전기사(과정평가형) 3과제 **용접 작업** 대비용 수평 필릿 용접 시뮬레이터입니다.
E4313 Ø3.2 용접봉, 각장 2–6 mm, 본 용접구간 150 mm 기준으로 판정합니다.

## 기능
- 아크 길이 유지 (봉이 타서 짧아지므로 손을 내려 주기)
- 목표 운봉 속도 가이드, 전류·작업각 설정
- 위치별 각장 그래프와 단면 보기 (언더컷·오버랩·융합 불량·기공·크레이터)
- 도면 ①②⑤ / ③④⑥ 시험 모드 (지급 봉 3개), 자유 연습
- 실격 사유 즉시 표시, 연습 기록 저장 (브라우저)

## 실행
`index.html` 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 배포하세요.

> 손 감각을 익히기 위한 단순화 모델이며 공식 채점기준이 아닙니다.
